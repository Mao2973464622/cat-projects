## 🎨 项目主题

这 6 个项目大致分为两类：

### 🎮 游戏工具类（迷枪 / 摸金）
- 迷枪图鉴：单文件 · 零依赖 · 离线可用 · 深色模式的**移动端枪械皮肤图鉴**查询网页
- 摸金交易行：**物价涨跌对比看板**，按快照对比分析交易行物价走势

### 🐾 猫猫个人站类（简介 / 成长 / 打卡 / 毕设）
- 均为纯 HTML/CSS/JS 的静态个人站点，风格统一、响应式适配移动端
- 成长记录站带武陵城风格（新中式科幻美学）、四主题切换、GitHub Pages 部署

## 🚀 快速开始

```bash
# 克隆本仓库
git clone https://github.com/Mao2973464622/cat-projects.git
cd cat-projects

# 双击任意子目录下的入口 HTML 即可运行（如迷枪图鉴）
# 或起本地静态服务
python3 -m http.server 8000
```

> ✅ 全部项目零依赖、无需 npm install、无需构建、多数可离线使用。
