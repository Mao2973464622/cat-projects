# 🎓 猫猫の毕设网站

> 📍 上级目录：[Cat Projects 合集](../README.md)

**毕业设计网站** · 纯 HTML/CSS/JS · 静态部署 · CRUD 功能

---

## 🚀 快速开始

```bash
# 双击 index.html 即可打开
# 或起静态服务（goods.json 数据经 HTTP 加载更稳）
python3 -m http.server 8000
```

---

## 📁 项目结构

```text
minimal-graduation/
├── index.html       # 主页
├── list.html        # 列表页
├── detail.html      # 详情页
├── add.html         # 新增页
├── edit.html        # 编辑页
├── developer.html   # 开发者页
├── common.css       # 公共样式
├── form.css         # 表单样式
├── goods_card.css   # 卡片样式
├── common.js        # 公共逻辑
├── crud.js          # CRUD 逻辑
├── goods.json       # 数据
└── README.md        # 本说明
```

---

## 🎮 功能特性

- 商品/物品数据展示（列表 / 详情 / 卡片）
- 增删改查（CRUD）操作
- 纯前端，数据存于 `goods.json`
