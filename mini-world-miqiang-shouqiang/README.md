## 🚀 快速开始

1. 双击 `迷枪图鉴-手枪.html` 即可打开（或拖进浏览器）。
2. 手机使用：把 HTML 发到手机用浏览器打开，或起静态服务：
   ```bash
   python3 -m http.server 8000
   ```
3. ✅ 无需 npm install、无需构建、无需联网。

---

## 🎮 功能特性

- **浏览**：首页按型号分块，点击展开双列卡片，点卡片弹属性详情
- **搜索**：皮肤名 / 型号名 / 系列名 / 属性名 四维模糊匹配，实时响应
- **筛选**：品质与属性自定义单选弹窗（带数量胶囊与内置搜索）
- **详情**：属性标签按品质色阶着色，一键复制属性粘贴到聊天
- **视觉**：主题联动（选品质切全局主题色）、神兵流光、错帧动画、触感反馈、深色模式
